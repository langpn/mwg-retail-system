## 3. Quy Chuẩn Kỹ Thuật Của Đồ Án (Backend, CSDL & Giao Diện)

### 3.1. Công nghệ bắt buộc vs Công nghệ mở rộng tự do
* **Khung công nghệ bắt buộc của môn học:** Hệ thống cốt lõi bắt buộc dùng **Spring Boot** (Maven, Java 17/21), **Spring Data JPA / Hibernate (Code-First)**, **MySQL Server + MySQL Workbench**, kiểm thử API bằng **Postman** ([PL1-B01 `25:20`–`27:26`](https://www.youtube.com/watch?v=4W27ZZ8sKfc&t=25m20s), [`01:17:54`–`01:18:30`](https://www.youtube.com/watch?v=4W27ZZ8sKfc&t=1h17m54s) | [PL2-B01 `01:22:59`–`01:23:56`](https://www.youtube.com/watch?v=1edL45bgl2g&t=1h22m59s)).
* **Công nghệ làm thêm (Frontend hiện đại / tính năng mở rộng):** Thầy khẳng định công nghệ mở rộng bên trên là **hoàn toàn tự do** (*"những cái gì các bạn dùng thêm thì thoải mái, muốn dùng thêm gì dùng, miễn phải thể hiện đầy đủ những gì học trong môn học vào bài tập lớn"* — [PL1-B01 `01:17:54`–`01:18:30`](https://www.youtube.com/watch?v=4W27ZZ8sKfc&t=1h17m54s), [`01:15:54`–`01:16:12`](https://www.youtube.com/watch?v=4W27ZZ8sKfc&t=1h15m54s)).

### 3.2. Quy mô Cơ sở dữ liệu & Mối quan hệ thực thể
* **Số bảng CSDL:** **Tối thiểu 6 bảng**, khung chuẩn là **từ 6 đến 10 bảng** (*"Triển khai thêm khoảng 2 bảng nữa là ra khoảng 6 bảng là vừa nha, còn nhiều hơn càng tốt, nhưng thầy nghĩ từ 6 đến 10 là ok rồi, 10 là cũng hơi nhiều à"* — [PL1-B11 `53:33`–`54:47`](https://www.youtube.com/watch?v=_0lFUb8cU4I&t=53m33s) | [PL2-S10 `55:32`–`56:46`](https://www.youtube.com/watch?v=kuJZxQC4n_4&t=55m32s)).
* **Độ sâu liên kết dữ liệu để đạt điểm 10:** Nếu chỉ làm quan hệ Master–Detail 2 cấp đơn giản (như Khoa – Sinh viên) thì trần điểm tối đa chỉ đạt **8/10**; muốn đạt **10/10** phải thiết kế phân cấp sâu nhiều tầng và lọc dữ liệu đa chiều ([PL2-S04 `27:45`–`28:44`](https://www.youtube.com/watch?v=xMQSY7vEis4&t=27m45s)).
* **JPA Relationships bắt buộc nắm vững:** `@Entity`, `@Table`, `@Id`, `@Column`, `@ManyToOne` + `@JoinColumn` (bên Nhiều giữ FK), `@OneToMany(mappedBy = "...")` (bên Một), xử lý **Circular Reference** khi xuất JSON và hiểu rõ chiến lược **Cascade vs Orphan Data** ([PL1-B10 `28:53`–`33:40`](https://www.youtube.com/watch?v=puX0LDumypE&t=28m53s) | [PL2-S09 `26:16`–`35:07`](https://www.youtube.com/watch?v=Ac686eKMcd4&t=26m16s)).

### 3.3. Yêu cầu RESTful API, Cấu trúc Package & Giao diện Đồ án
* **Tự cung cấp REST API nội bộ (Cấm MockAPI):** Backend Spring Boot phải tự viết đầy đủ các endpoint CRUD (`GET`, `POST`, `PUT`, `DELETE`) trả JSON; cấm dùng Fake/Mock API bên ngoài ([PL2-B05 `31:16`–`32:17`](https://www.youtube.com/watch?v=acNPtD44jWU&t=31m16s) | [PL1-B06 `22:28`](https://www.youtube.com/watch?v=SMDSzotHLF0&t=22m28s), [`02:02:40`](https://www.youtube.com/watch?v=SMDSzotHLF0&t=2h02m40s)).
* **Phân chia subpackage chuẩn mực:** Phải tách rõ `.controller`, `.service`, `.repository`, `.entity` dưới root package. Để dồn tất cả file vào 1 cục sẽ **không được chấm điểm** ([PL1-B07 `02:02:26`](https://www.youtube.com/watch?v=XpgBaeJS1JI&t=2h02m26s), [PL1-B08 `06:14`](https://www.youtube.com/watch?v=YxOeRIoG_dI&t=6m14s) | [PL2-S07 `16:05`](https://www.youtube.com/watch?v=64I1w6eXR4g&t=16m05s)).
* **Giao diện Đồ án phải gần giống thực tế (khác hẳn thi giữa kỳ):**
  * **Lời thầy:** *"Đó là thi giữa kỳ! Bài tập lớn phải làm cho nó gần gần giống thực tế, làm đủ các trang như là trang chủ, trang chi tiết..."* ([PL1-B10 `02:23:32`–`02:23:49`](https://www.youtube.com/watch?v=puX0LDumypE&t=2h23m32s); kết hợp [PL1-B11 `53:51`–`54:09`](https://www.youtube.com/watch?v=_0lFUb8cU4I&t=53m51s)).
* **Hiệu năng tải trang < 3 giây & Đường dẫn API tương đối:**
  * Không được để trang trắng chờ `window.onload` mới gọi API nạp danh mục cơ bản gây trễ > 3 giây ([PL1-B08 `08:05`](https://www.youtube.com/watch?v=YxOeRIoG_dI&t=8m05s) | [PL2-S07 `16:24`–`18:43`](https://www.youtube.com/watch?v=64I1w6eXR4g&t=16m24s)).
  * Khi giao diện và API chạy chung trên cùng ứng dụng Spring Boot, JavaScript gọi API phải dùng **relative path `/api/...`**, không hardcode `http://localhost:8080/api/...` ([PL1-B08 `01:41:00`](https://www.youtube.com/watch?v=YxOeRIoG_dI&t=1h41m00s) | [PL2-S07 `23:46`–`26:57`](https://www.youtube.com/watch?v=64I1w6eXR4g&t=23m46s)).

  2. Bối cảnh, lý do chọn đề tài & mục tiêu, phạm vi thực hiện vừa sức môn học.
  3. Điểm mới / sự khác biệt của đề tài so với các đề tài thông thường.
